# FurniSpace 🛋️

> A modern furniture e-commerce platform featuring new furniture shopping, resale marketplace for pre-loved items, and intelligent "Complete My Room" budget-based bundle planner.

## Overview
FurniSpace is an MVP web application built with Python Flask, SQLite, Jinja2 templates, and vanilla modern CSS & JavaScript.

### Core Features
- **Authentication & Role-Based Access Control**: Customer registration & login, secure admin portal, password hashing.
- **New Furniture Shop**: Curated catalogue across 8 categories with search, category filtering, price filtering, and sorting.
- **Product Comparison**: Side-by-side comparison of up to 3 products across specifications.
- **Resale Marketplace**: Peer-to-peer pre-loved furniture listings with seller submission, pending review workflow, and admin moderation.
- **Complete My Room**: Deterministic budget-based room bundle recommendation engine with item swapping and bundle-to-cart checkout.
- **Shopping Cart & Demo Checkout**: Server-validated stock check, transactional order placement, order history tracking.
- **Admin Dashboard**: Catalog inventory control, order fulfillment status management, resale listing moderation.

## Tech Stack
- **Backend**: Python 3, Flask, SQLite3, SQLAlchemy / Werkzeug
- **Frontend**: HTML5, Jinja2, Vanilla CSS3 (warm organic palette), Vanilla JavaScript
